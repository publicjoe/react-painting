# PaintLog

Track the build, prime, paint and base progress of tabletop miniatures. Organise models into projects and categories, with a per-project painted-progress bar. Data lives in the browser's `localStorage`; use **Export** / **Import** in the sidebar to back it up or move it between browsers.

Built with React 19, TypeScript, Vite and Tailwind CSS v4.

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the dev server (http://localhost:5173) |
| `npm run build` | Type-check and build for production |
| `npm run lint` | Run ESLint |
| `npm test` | Run unit tests (Vitest) |
| `npm run preview` | Preview the production build |

See [walkthrough.md](walkthrough.md) for a feature tour.
